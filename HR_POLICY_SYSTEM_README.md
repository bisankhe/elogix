## 🛡️ TRANSACTION BLOCKING FLOW

```
Employee tries to process salary
           ↓
Call: POST /api/v1/hr-policies/check-transaction
      { transaction_type: "salary" }
           ↓
Backend checks: any unread mandatory policies?
           ↓
YES → { can_proceed: false, blocking_policies: [...] }
   → Show blocking modal with list of unread policies
   → Employee redirected to /hr-policies
           ↓
Employee reads + signs all policies
           ↓
NO → { can_proceed: true }
   → Salary processing continues ✅
```
