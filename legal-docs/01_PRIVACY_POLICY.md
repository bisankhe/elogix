We process personal data under the following legal bases:

| Processing Activity | Legal Basis |
|---|---|
| Employee payroll processing | **Contract performance** (Art. 6(1)(b) GDPR) |
| Attendance & leave tracking | **Legitimate interests** (Art. 6(1)(f) GDPR) |
| AI-powered HR analytics | **Consent** (Art. 6(1)(a) GDPR) |
| Compliance reporting | **Legal obligation** (Art. 6(1)(c) GDPR) |

- Full name, date of birth, gender, nationality
- National ID / Passport number
- Contact information (email, phone, address)

- Employment history and qualifications
- Bank account details (for payroll)

**We only collect sensitive data where legally permitted and with explicit consent or legal obligation.**

### 4.3 Technical Data
- IP addresses and device identifiers
- Browser type and version
- Login timestamps and session data
- System usage logs (anonymized)

### 4.4 Candidate Data (ATS Module)
- CV/Resume contents
- Interview notes and assessments
- Background verification results
- Reference check information

## 8. DATA SECURITY

We implement the following security measures:
- **AES-256 encryption** at rest for all personal data
- **TLS 1.3** for all data in transit
- **Role-Based Access Control (RBAC)** — 7 access levels
- **Multi-tenant isolation** — separate database schemas per client
- **Audit logs** — all data access is logged and monitored
- **Multi-Factor Authentication (MFA)** available for all accounts
- **Annual VAPT** (Vulnerability Assessment & Penetration Testing)
- **ISO/IEC 27001** Information Security Management System

### 9.1 Under GDPR (EU/UK Users)
- ✅ **Right of Access** — request a copy of your data
- ✅ **Right to Rectification** — correct inaccurate data
- ✅ **Right to Erasure** ("Right to be Forgotten")
- ✅ **Right to Restriction** — limit how we process your data
- ✅ **Right to Portability** — receive your data in machine-readable format
- ✅ **Right to Object** — object to processing based on legitimate interests
